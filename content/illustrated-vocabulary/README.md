## ESP32 연결 상태

**원본 자료를 프로젝트로 가져온 단계이며, 기기에 적용하지 않았다.** 현재 기기는 기존 공개 단어장 8개를 사용한다.

추가 연결 작업에는 기기 규격의 작은 PNG, 화면에 맞는 한글 폰트 또는 영어 풀이, 예문·발음, JSONL 목록 및 128KiB 파일시스템 용량 대응이 필요하다. 큰 PNG 원본을 그대로 기기 단어장에 올리거나 폴더 전체를 플래시에 넣으면 안 된다. 그림 설명(`subject`)은 이미지 제작 설명이며 학습용 정의·예문으로 간주하지 않는다.
