## 퀴즈 정답 그림 공개 — 2026-11-07 (최신)

**v0.12.0을 COM4 / ILI9341에 적용**했다. 답을 고르면 보기 대신 정답 그림·영단어·한글 뜻을 보여 준다. 정답/오답 모두 공개하고, 다음 문제/결과 보기는 직접 눌러 이동한다. 문제를 풀기 전에는 그림이 숨겨진다.

- 기존 단어장/그림 캐시와 그림 버퍼를 재사용한다. 퀴즈 중 카드 위치를 잠시 바꾸고 닫기/회차 종료 시 원래 학습 카드로 복원한다. 이미지와 문제의 단어가 일치할 때만 표시한다.
- 연속 기기 검사에서 조회 실패/재시작을 발견해 조회 성공 때만 단어를 확정하고 실패 시 3초 간격으로 재시도하도록 했다. 긴 파일 스캔은 32줄마다 작업 실행 시간을 양보한다. 조회 파일은 카드 로드 전 닫는다. 이후 정답/오답 번갈아 **10문제 연속 그림 검증 통과**, 자료 조회 재시도 후 복구도 관찰했다. 마지막 재부팅부터 시험/캡처 종료까지 145초 이상 기기가 유지됐다.
- 호스트 8종 검사와 두 패널 빌드 통과. ILI9341 RAM 122,824B(37.5%), 앱 1,994,577B(84.5%). 앱 영역만 플래시/해시 검증했다.
- 실제 `persimmon` 그림/영단어/한글 뜻/다음 버튼을 `build/quiz-picture-answer.png`로 확인했다. 증거 `build/quiz-picture-verification.json`, `.log`, `build/quiz-picture-build.log`, `build/quiz-picture-flash.log`.
- 체험 모드 검사 후 일반 화면으로 복원했다. eraser, 캐시 10/10, 저장 40점, 학습 revision 0/newToday 0/복습 대기 4 유지. 최종 상태 `build/quiz-picture-final.json`.
- 기본 단어장과 다른 사용자 정의 원격 자료에 퀴즈 단어가 없거나 네트워크/캐시가 없으면 그림은 로딩 상태로 남을 수 있다. 잘못된 다른 단어의 그림은 표시하지 않는다.

다음 시작 문장: `docs/HANDOFF.md` 최신 v0.12.0 절부터 읽어 주세요. 퀴즈 답 선택 후 그림 공개까지 적용/기기 검증했고 40점과 기존 학습 기록을 유지했습니다. 그림은 기존 원격 자료/캐시를 사용합니다.

HTTP 작업은 하나씩 FreeRTOS 작업에서 처리하고, 완료 결과의 검증/게시와 그림 갱신은 메인 루프에서 수행한다. 그림 WMR1·WAV 헤더/길이를 검증하고 실패 시 30초→120초→600초로 재시도한다. 연결 복구 시 대기 시간을 초기화한다. 현재 후보 밖의 파일만 정리하며 NTP 전에는 이전 부팅의 미리 받은 자료를 지우지 않는다. 512KiB 예산 안에 6쌍과 임시 파일이 들어감을 컴파일 시 검사하고 학습 이력 저장 여유를 별도로 남긴다. 음성 재생·날씨·자료 다운로드는 동시에 네트워크 작업을 시작하지 않는다. 발음 요청은 진행 중인 작업 후 시작하며 다시 누르면 취소된다.

- 정적 RAM 118.7KB(예산 ~125KB라 여유 없음) → **정적 대형 버퍼 금지**. PNGdec `PNG` 객체 하나가 45.7KB(32KB zlib 윈도우 포함)라 부팅 후 첫 디코드 때 힙에 1회 할당(`new`, 해제 없음), 아트 픽셀도 최대치(120×88×2=21KB)로 1회 할당 후 매일 재사용 — 일일 할당/해제가 없어 파편화 걱정 없음.
- 힙 여유 ~180KB. 동시 최대 소비: PNG 45.7 + 아트 21 + TLS 핸드셰이크 ~40 + WiFi 런타임 ~50 → 실측 필요(하드웨어 검증 항목).
- Flash 앱 83.7% (321KB 여유). `huge_app.csv` 전환 시 3MB로 확장 가능하나 OTA 슬롯 상실.
- 단어장 용량 상한: manifest ~100B/단어 + 그림 1개 → 128KB FS에서 manifest만 약 1,000단어. 1,000을 넘기면 파티션 재배치 필요.

3. **UI 확장**: 오늘 단어 + 지난 며칠 복습 카드, 퀴즈 모드(뜻 보고 단어 고르기), 손으로 쓰기 캔버스(`lv_canvas` + 터치, 스펠링 연습). 라벨이 한 줄인 것도 이 단계에서 여러 줄(`LV_LABEL_LONG_WRAP` + 높이 계산)로 개선. 단어 데이터는 이제 words.jsonl이 단일 소스.
4. **한글 뜻 표시**: words.jsonl의 `m`/`e`에 한글을 넣으면 현재 화면에서 깨진다(Montserrat는 ASCII 전용). NotoSansKR 서브셋(실제 사용 음절만 추리면 수백 KB)을 lv_font_conv로 만들어 연결. 웹 포털의 한글은 브라우저가 그리므로 문제없음.
5. **시간 관련 확인**: 타임존은 `include/app_config.hpp`의 `kTimezone`(`KST-9`). Wi-Fi 일시 실패로 부팅하면 캐시된 어제 카드 또는 내장 샘플이 뜨는 것이 설계된 동작.
6. **(선택) 야간 자동 밝기/화면 끄기**: NTP 시간이 있으니 시간대별 밝기 조절이 가능. `display_.setBrightness()`로 즉시 적용된다.
7. **(선택) S3 이전**: 사용자가 그림 몇백 장을 준비 중. 16MB S3 보드로 옮기면 파티션/메모리 제약이 사라진다. `platformio.ini` 보드 교체 + `display_driver.hpp` 패널/정전식 터치 교체가 주된 작업.

## 주의 (원본 프로젝트 정책 승계)

- 설정 포털은 로컬 HTTP다. 공용 네트워크에서 설정하지 말고 신뢰하는 가정·작업실 LAN에서만 사용.
- 공개 저장소 문서에는 Wi-Fi 이름, Wi-Fi 비밀번호, 내부 IP를 기록하지 않는다.
- 커밋은 원격(main)에 즉시 푸시해 다음 세션이 로컬 상태와 무관하게 이어받을 수 있게 한다.
