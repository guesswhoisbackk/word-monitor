# 단어 퀴즈 — v0.11.0

## 사용

일반 화면의 **더 배우기**에서 **배운 단어 퀴즈** 또는 **전체 단어 퀴즈**를 선택한다. 영단어 하나와 한글 뜻 보기 6개가 나온다. 보기는 2열 3행이다. 배운 단어는 실제 AGAIN/GOT IT 기록이 있는 기본 단어장 항목이다. 배운 단어가 없으면 전체 단어 퀴즈로 이동할 수 있다. 한 회에 최대 10문제이며 적게 배웠으면 해당 수만큼 출제한다.

첫 선택이 정답이면 +10점, 틀리면 정답을 초록색으로 표시하고 추가 점수 없이 다음 문제로 이동한다. 오답을 다시 눌러 정답으로 바꿀 수 없다. 문제마다 한 번만 채점한다. 결과 화면에서 이번 정답 수/획득 점수와 누적 포인트를 확인하고 한 번 더 풀 수 있다. 새 회차의 정답도 점수를 받는다. 중간에 닫아도 이미 받은 점수는 유지된다.

## 구현과 저장

- 기본 893단어의 수정된 뜻을 펌웨어에 포함해 네트워크 없이 출제한다. 사용자 정의 단어장은 퀴즈 대상에 포함되지 않는다.
- 회차 내 문제는 중복하지 않는다. 보기의 동일한 뜻과 포함 관계(기타/통기타 등)를 제외한다. 이 규칙이 모든 유의어의 동등성을 판정하지는 않는다.
- `QuizGame`은 기존 학습 기록을 조회하며 `grade`를 호출하지 않는다. 퀴즈 중 오늘 반복 재생은 대기하고 닫은 뒤 이어진다.
- `/quiz-v1.bin`에 점수/응답 수/정답 수와 체크섬을 저장한다. 임시 파일 쓰기→재검증→이름 교체가 성공한 뒤 점수를 반영한다. 저장 실패하면 첫 선택을 고정하고 **다시 저장**으로 재시도한다. 손상된 기존 저장 파일은 덮어쓰지 않는다.
- `/api/quiz`는 읽기 전용 상태다. 일반 퀴즈의 정답 키는 채점 후에만 제공한다.
- USB `m`: 더 배우기 메뉴, `q`: 배운 단어 퀴즈, `Q`: 전체 단어 체험 퀴즈, `1`~`6`: 보기 선택, `v`: 다음/재저장, `c`: 닫기. 대문자 Q는 점수와 학습 기록을 저장하지 않는 기기 검증용이다.
- 기존 USB `t/n`은 오늘 복습 진입/종료를 유지한다. 기기 캡처는 퀴즈에서 `capture_screen.py COM4 build/quiz.png`처럼 모드 인자 없이 사용한다.

## 검증

호스트에서 3,000문제의 보기 중복/포함 관계 제외·정답 위치 분포·회차 문제 중복 방지, 중복 터치, 저장 실패/재시도, 재부팅, 임시 파일 정리, 손상 파일 보호, 학습 파일 불변을 확인했다. 실제 화면과 터치는 ESP32 재연결 후 확인해야 한다. 이번 개발 중 기기가 분리되어 플래시하지 않았다.

```powershell
$env:PYTHONUTF8='1'
.venv/Scripts/python.exe scripts/build_quiz_content.py
.venv/Scripts/python.exe scripts/build_sentence_translations.py
.venv/Scripts/python.exe scripts/make_kr_font.py
cmd /c scripts\test_host.cmd
.\scripts\build.ps1 -Environment all
```

## 2026-11-07 실기기 확인

ILI9341에 v0.11.1을 앱 플래시했다. 체험 10문제(8정답/2오답), 중복 입력 차단, 결과 집계, 실제 화면 캡처, 학습/포인트 기록 불변을 확인했다. USB 종료는 기존 Wi-Fi 검사와 겹치지 않게 `c`로 변경했다. 사용자가 실제 터치로 정답 +10점과 다음 문제 동작을 확인했다. 실제 획득한 40점(응답 4/정답 4)이 재부팅 후 복원됨을 API로 검증했다. 학습 기록과 날씨도 정상이며, 재부팅 시 진행 중 회차는 종료되고 누적 점수는 유지된다. 증거는 `build/quiz-reboot-verification-1107.json`이다.

## 답을 고른 뒤 그림 보기 — v0.12.0

정답/오답을 고른 뒤에는 보기 목록을 정답 그림과 한글 뜻으로 바꾼다. 다음 문제/결과 보기는 사용자가 눌러 이동한다. 문제를 풀기 전에는 그림을 공개하지 않는다.

퀴즈의 단어를 기존 캐시/단어장에서 찾아 동일한 WMR 그림과 다운로드 재시도 기능을 사용한다. 추가 그림 버퍼는 할당하지 않는다. 퀴즈 동안 원래 학습 카드 위치를 보관하고 닫기/회차 종료 시 복원한다. 원격 단어장 갱신과 오늘 복습의 날짜 전환은 퀴즈가 끝난 뒤 처리한다. 점수/학습 저장 형식은 유지한다. 기본 단어장과 다른 사용자 정의 단어장에 대상 단어가 없거나 네트워크가 끊겨 캐시 그림이 없으면 그림을 받지 못할 수 있다.

실기기에서 정답/오답을 번갈아 10문제의 그림 출처를 검증하고 실제 화면을 캡처했다. 조회 실패 재시도와 긴 스캔 중 작업 양보를 보완한 최종 버전을 적용했다. 종료 후 원래 카드와 저장 40점이 복원/유지됐다. 증거: `build/quiz-picture-verification.json`, `build/quiz-picture-answer.png`, `build/quiz-picture-final.json`.
