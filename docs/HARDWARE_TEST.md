## v0.5.3 어느 면에서든 평가·자동 진행 (2026-10-10 적용, 실물 확인 진행 중)

- **그림이 나온 앞면에서 바로 GOT IT/AGAIN을 눌러 저장되는지, 저장 즉시 다음 카드로 넘어가는지 확인.** (v0.5.2까지는 뜻을 본 뒤에만 평가가 가능했고 NEXT를 또 눌러야 해서 "눌러도 안 넘어가는" 것처럼 보였다 — 플래시 덤프로 확인한 실제 사례: pencil 재평가가 계속 무시됨.)
- 기한이 지난 복습 단어가 있으면 GOT IT/AGAIN을 평가하기 전까지 NEXT·자동 진행 모두 그 단어를 계속 보여주는지 확인(설계 동작).
- 하루 새 단어 수를 다 쓰면 "ALL DONE - COME BACK LATER"가 뜨고 더 진행하지 않는지 확인. 웹 설정에서 0~20 조절.
- `[ui] grade <단어> -> GOT IT/AGAIN` 로그가 평가마다 남는지 확인.

## v0.5.1 예문·발음·스트리밍 오디오 검증 (2026-10-10 시리얼 로그로 일부 확인, 소리 미확인)

- 부팅 로그에 `[wb] pre-TLS heap=... largest=...`가 나온 뒤 `manifest synced: 893 words`로 이어지는지 확인(pre-TLS heap ≈116KB, largest ≈70KB가 정상. 67KB/41KB로 떨어지며 `SSL - Memory allocation failed`가 나오면 메모리 회귀다).
- 카드를 터치해 **예문이 뜻 아래 회색 영어 문장으로 표시**되는지 확인(jsDelivr `@main` 갱신 지연 시 이전 manifest로 몇 시간 동기화되지 않을 수 있다). v0.5.2부터 그림은 HINT 없이 앞면에 항상 표시된다.
- **SPEAK를 눌러 Zira 음성 발음이 나오는지 확인**(v0.5.1은 LittleFS 스트리밍 재생). 첫 재생은 다운로드로 수 초 걸리고, 같은 단어 재생은 캐시로 즉시 나야 한다. STOP으로 끊기, 재생 중 카드 뒤집기/NEXT도 시험.
- 발음 다운로드 후 재부팅해 같은 단어가 캐시로 바로 재생되는지, 다른 단어는 새로 내려받는지 확인. Wi-Fi 없이 캐시된 발음 재생, 캐시 없는 발음은 오류 안내가 떠야 한다.
- `[audio] start/end` 로그의 heap·최대 연속 블록·스택 여유가 재생 전후로 크게 감소·누수되지 않는지 확인.

## v0.5.0 893단어 콘텐츠·한글 폰트 검증 (2026-10-10 시리얼 로그로 일부 확인, 화면·터치 미확인)

- 파티션 테이블 교체(`partitions_wordmon.csv`) 후 최초 부팅: LittleFS 1.625MiB가 깨끗하게 포맷·마운트되고 Wi-Fi 설정이 유지되는지 확인. 부팅 초반 `No core dump partition found` 에러는 coredump 파티션 제거로 인한 정상 로그다.
- 893단어 manifest 동기화 후 `manifest synced: 893 words`와 카드 선택 로그 `card #0: pencil (art)` 확인. jsDelivr `@main` 갱신 지연 시 manifest 다운로드 실패가 반복돼도 10분 주기 재시도로 자동 복구되어야 한다.
- 카드를 터치해 **한글 뜻이 깨지지 않고 표시**되는지 육안 확인(맑은 고딕 16px 서브셋, 526음절). 뜻에 영어가 섞여 있어도 표시되어야 한다.
- HINT로 그림(연필 등)이 카드 배경색 위에 자연스럽게 합성되어 표시되는지, NEXT로 단어를 바꿔도 그림이 정상 교체되는지 확인. 더 이상 PNG 디코딩을 하지 않으므로 동기화 직후에도 그림이 사라지지 않아야 한다.
- 그림 캐시는 현재 카드 하나만 유지된다. 카드가 바뀌면 이전 그림 파일이 삭제되는지 `/wb` 로그로 확인.
- 재부팅 후에도 캐시된 893단어·그림·학습 기록이 유지되는지 확인.
- 128KiB → 1.625MiB 확대 후에도 평가 저장·공간 부족 처리 정책이 그대로 동작하는지 확인(호스트 테스트는 통과됨).

## v0.4.0 순차 학습 검증 (실물 미검증)

- ILI9341 앱을 적용하되 파티션과 NVS/LittleFS를 지우지 않는다. 기존 단어의 복습 시각·단계가 유지되고 `NEW 0/5`(업그레이드 첫날)로 시작하는지 확인.
- 첫 평가 5개 뒤 새 단어 저장이 막히고 기한 복습은 계속 가능한지 확인. AGAIN도 새 단어 수에 포함되며 재복습·SPEAK·단순 조회는 포함되지 않아야 한다.
- 세 번째 새 단어 학습 후 재부팅해 `NEW 3/5`가 복원되는지 확인. 평가하지 않고 재부팅한 새 단어는 동일한 미학습 순서로 돌아와야 한다.
- KST 자정 후 0/5로 시작하는지 확인. 날짜를 여러 날 건너뛰어도 다음 미학습 단어를 선택하고 밀린 신규 학습량을 누적하지 않아야 한다.
- NEXT에서 기한이 가장 오래 지난 단어가 먼저 나오고 답이 숨겨지는지 확인. 오늘의 신규 학습과 복습이 끝났으면 완료 안내를 확인.
- 웹 설정 하루 수 0/1/20 저장 및 재부팅 확인. 0에서는 새 단어를 평가할 수 없어야 한다. 기본 음량과 Wi-Fi 설정이 유지되어야 한다.
- 목록 순서 변경·활성 단어 삭제 후 동기화 확인. 배운 단어가 신규로 중복 도입되거나 삭제된 단어가 계속 평가되지 않아야 한다.
- 파일시스템 공간을 채운 상황에서 평가 시 캐시만 비우고 이력/manifest를 유지하는지 확인. 스피커 재생 중 평가·NEXT·재다운로드를 함께 검사한다.
- 별도 시험 기기에서 저장 도중 전원 차단·마운트 실패·기록 손상 시험. 기존 기록이 유실되거나 자동 초기화되지 않아야 한다. 운영 기기의 학습 기록으로 파괴 시험을 하지 않는다.
- 새 화면 날짜/NEW 수와 NEXT 라벨, 저장 실패/완료 안내가 240×320에서 읽히는지 확인.

아래는 이전 버전 체크리스트다. v0.4.0에서 REVIEW 버튼명은 NEXT로 바뀌었다.

## v0.3.0 오디오 추가 검증 (실물 미검증)

- SPEAK 단자에 8Ω·1W 스피커를 연결하고 ILI9341 v0.3.0 앱 적용. 새 설정 없는 NVS에서도 음량20으로 동작하는지 확인.
- 기본 8단어에서 SPEAK로 정확한 단어 발음을 듣고 STOP, 연속 탭, 재생 중 카드 뒤집기/스크롤/REVIEW를 시험. 터치 GPIO25가 계속 작동해야 함.
- 0(무음), 20, 60 설정 저장/재부팅과 소리 크기·왜곡 확인. 끝 음절 누락, 재생 전후 큰 클릭/지속 잡음 여부 확인.
- 그림이 있는 카드에서 외부 WAV 첫 다운로드/재생을 시험하며 `[audio]` 힙·최대 연속 블록·스택 로그 확인. 여러 카드에서 반복해 누수/파편화/재부팅이 없는지 확인.
- 외부 WAV 다운로드 후 Wi-Fi 없이 같은 파일 재생, 다른 미캐시 파일은 오류 표시. 서버 404/잘린 파일/잘못된 WAV/큰 파일에 대해 소리를 출력하지 않는지 확인.
- 다운로드 중 STOP/REVIEW, TLS 응답 지연을 시험. UI는 반응하고 취소된 발음을 뒤늦게 재생하지 않아야 함.
- WAV 교체 중 재부팅/FS 공간 부족에서 다른 단어의 음성을 재생하지 않는지 확인. 공간 부족은 다운로드한 발음의 RAM 재생만 가능할 수 있음.
- 기본 음성 및 WAV 예제는 `docs/audio-sample/`, 명세와 호스팅 방법은 `docs/AUDIO.md` 참고.

v0.1.1의 화면·터치·Wi-Fi·단어장 동기화는 이후 실물 검증 완료되었습니다(HANDOFF.md 참고). **v0.2.0은 아직 실물 미검증**이며, 이 문서 끝의 추가 검증 항목부터 확인합니다. 아래 초기 체크리스트 기록은 과거 상태입니다.

**2026-09-17 진행 상황**: 1장 확인 완료(ESP32-2432S028R, COM4), 2장 완료(**ILI9341 확정**, ST7789는 흰 화면), 3장 화면 표시 확인·터치 미확인, 4~6장 대기(집 Wi-Fi 설정 연기 — HANDOFF의 "집에 가서 할 일" 참조).

## 1. 보드 확인

- 보드 모델 표기 확인. 이 스켈레톤의 핀 배치는 `ESP32-2432S028R`(일명 CYD) 기준
- 다른 모델이면 `include/display_driver.hpp`와 `include/app_config.hpp`의 핀을 그 보드에 맞게 먼저 수정
- 앞·뒷면을 사진으로 남기고 USB 단자 종류 확인
- 2.4GHz Wi-Fi에 접속 가능한지 확인

## 2. 첫 플래싱

1. `build/WordMonitor-v0.1.0-cyd-st7789-merged.bin`을 주소 `0x0`으로 기록합니다.
2. 완료 후 RESET을 한 번 누릅니다.
3. 화면이 보이지 않거나 색·좌표가 심하게 잘못되면 전원을 끕니다.
4. 같은 방법으로 `WordMonitor-v0.1.0-cyd-ili9341-merged.bin`을 기록해 비교합니다.

bambu-monitoring의 실증 보드는 ILI9341이었습니다. 새 보드도 ST7789에서 실패하면 ILI9341일 가능성이 높습니다. 두 파일을 번갈아 기록해도 보드가 손상되는 것은 아니지만, 플래싱 중에는 USB를 분리하지 않습니다.

## 3. 화면과 터치

- 화면 방향이 세로 240×320이고 USB 전원부가 아래인지
- 어두운 배경에 `WORDMON` 제목, `WORD OF THE DAY` 카드, 단어가 보이는지
- 카드를 터치했을 때 뜻과 예문이 나타났다 사라지는지
- 터치 X/Y가 뒤집혔거나 모서리에서 어긋나는지

터치가 어긋나면 `include/app_config.hpp`의 네 보정값(`kTouchMinX` 등)을 조정합니다.

## 4. 네트워크 설정

- `WordMon-XXXX` AP가 나타나는지
- 비밀번호 `wordmon1`로 접속되는지
- `http://192.168.4.1` 설정 페이지가 열리는지
- 저장 후 자동 재부팅되는지
- 집 Wi-Fi 연결 후 화면에 새 IP가 보이는지

## 5. 날짜와 단어 전환

- Wi-Fi 연결 후 최대 1~2분 안에 상단 날짜가 `SEP 17 2026 - DAY 260` 형태로 나타나는지 (NTP 시간 수신)
- 날짜가 나타나기 전에는 `TIME WAITING FOR WI-FI`와 첫 번째 단어가 고정되는 것이 정상
- 가능하면 자정 전후에 켜 두고 날짜와 단어가 바뀌는지 확인

## 6. 인터넷 단어장 (v0.1.0 신규)

사전 준비: 단어장은 이미 GitHub에 있다 — `https://github.com/guesswhoisbackk/wordbook`.
기기에 입력할 URL: `https://cdn.jsdelivr.net/gh/guesswhoisbackk/wordbook@main`
(로컬 클론 `C:\antigravity\wordbook`, 갱신은 `scripts\push_wordbook.ps1`. NAS 등 다른 서버를 쓸 때는 평문 http://도 지원한다.)

- 설정 페이지(`http://<기기IP>/`)에 "단어장 (인터넷)" 섹션이 있는지
- 준비한 URL을 입력·저장한 뒤 재부팅하면 하단 상태가 `WB 8`처럼 단어 수로 바뀌는지
- 오늘 차례 단어가 내장 샘플이 아닌 단어장의 단어로 바뀌는지 (단어 수에 따라 며칠씩 걸릴 수 있음)
- 그림 있는 단어(`apple`) 차례에 그림이 카드에 뜨는지 — 그림 확인을 위해서는 `words.jsonl`에서 `apple`을 오늘 순번 위치로 옮기면 바로 시험 가능
- 인터넷 연결을 끊고 재부팅해도 캐시된 단어장(`WB CACHED`)으로 같은 카드가 뜨는지
- URL을 지우고 저장하면 내장 샘플 단어로 돌아가는지
- 시리얼 로그에 `[wb]` 줄이 오류 없이 나오는지 (manifest synced, card #N, art)

## 7. 안정성

- 30분 이상 켜 두고 재부팅·멈춤·화면 깨짐이 없는지
- 공유기 재시작 후 다시 연결되는지
- 설정(SSID, 밝기, 단어장 URL)이 재부팅 후 유지되는지

## 문제가 생기면 받을 정보

- 보드 앞·뒷면 사진과 모델 표기
- 사용한 BIN 파일명
- 화면 사진 또는 짧은 영상
- USB 시리얼 모니터 115200 baud 로그
- 화면 하단에 표시된 현재 IP 또는 AP 이름

이 정보가 있으면 디스플레이 핀, 터치 보정, 패널 종류, NTP 문제를 구분해서 고칠 수 있습니다.
## v0.2.0 추가 검증 (아직 실물 미검증)

- 기존 설정·캐시가 있는 ILI9341 보드에 앱 영역만 업데이트한 뒤 Wi-Fi 설정이 유지되는지 확인.
- 앞면에서 AGAIN/GOT IT이 비활성화되고, 정답을 확인한 뒤에만 평가할 수 있는지 확인.
- 긴 단어가 가로 스크롤되고 긴 뜻/예문은 답 영역에서 세로 스크롤되는지 확인. 스크롤이 카드 뒤집기로 잘못 인식되지 않아야 함.
- AGAIN → REVIEW → 완료 안내 → 10분 후 REVIEW에서 같은 단어가 정답을 숨긴 상태로 나오는지 확인.
- GOT IT 직후 재평가 방지, 재부팅 후 예약 유지, 기한 지난 단어 우선 선택을 확인.
- HINT 그림 표시 후 GOT IT이 막히고 AGAIN으로 평가되는지 확인. 그림이 없는 카드에서는 HINT 비활성화.
- 서로 크기가 다른 PNG 카드 간 전환 시 옛 그림/크기가 남지 않는지 확인.
