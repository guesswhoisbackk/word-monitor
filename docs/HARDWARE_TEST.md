# 실제 보드 검증 체크리스트

v0.1.1의 화면·터치·Wi-Fi·단어장 동기화는 이후 실물 검증 완료되었습니다(HANDOFF.md 참고). **v0.2.0은 아직 실물 미검증**이며, 이 문서 끝의 추가 검증 항목부터 확인합니다. 아래 초기 체크리스트 기록은 과거 상태입니다.

**2026-09-17 진행 상황**: 1장 확인 완료(ESP32-2432S028R, COM4), 2장 완료(**ILI9341 확정**, ST7789는 흰 화면), 3장 화면 표시 확인·터치 미확인, 4~6장 대기(집 Wi-Fi 설정 연기 — HANDOFF의 "집에 가서 할 일" 참조).

## 1. 보드 확인

- 보드 모델 표기 확인. 이 스켈레톤의 핀 배치는 `ESP32-2432S028R`(일명 CYD) 기준
- 다른 모델이면 `include/display_driver.hpp`와 `include/app_config.hpp`의 핀을 그 보드에 맞게 먼저 수정
- 앞·뒷면을 사진으로 남기고 USB 단자 종류 확인
- 2.4GHz Wi-Fi에 접속 가능한지 확인

## 2. 첫 플래싱

1. `build/WordMonitor-v0.1.0-cyd-st7789-merged.bin`을 주소 `0x0`으로 기록합니다.
2. 완료 후 RESET을 한 번 누릅니다.
3. 화면이 보이지 않거나 색·좌표가 심하게 잘못되면 전원을 끕니다.
4. 같은 방법으로 `WordMonitor-v0.1.0-cyd-ili9341-merged.bin`을 기록해 비교합니다.

bambu-monitoring의 실증 보드는 ILI9341이었습니다. 새 보드도 ST7789에서 실패하면 ILI9341일 가능성이 높습니다. 두 파일을 번갈아 기록해도 보드가 손상되는 것은 아니지만, 플래싱 중에는 USB를 분리하지 않습니다.

## 3. 화면과 터치

- 화면 방향이 세로 240×320이고 USB 전원부가 아래인지
- 어두운 배경에 `WORDMON` 제목, `WORD OF THE DAY` 카드, 단어가 보이는지
- 카드를 터치했을 때 뜻과 예문이 나타났다 사라지는지
- 터치 X/Y가 뒤집혔거나 모서리에서 어긋나는지

터치가 어긋나면 `include/app_config.hpp`의 네 보정값(`kTouchMinX` 등)을 조정합니다.

## 4. 네트워크 설정

- `WordMon-XXXX` AP가 나타나는지
- 비밀번호 `wordmon1`로 접속되는지
- `http://192.168.4.1` 설정 페이지가 열리는지
- 저장 후 자동 재부팅되는지
- 집 Wi-Fi 연결 후 화면에 새 IP가 보이는지

## 5. 날짜와 단어 전환

- Wi-Fi 연결 후 최대 1~2분 안에 상단 날짜가 `SEP 17 2026 - DAY 260` 형태로 나타나는지 (NTP 시간 수신)
- 날짜가 나타나기 전에는 `TIME WAITING FOR WI-FI`와 첫 번째 단어가 고정되는 것이 정상
- 가능하면 자정 전후에 켜 두고 날짜와 단어가 바뀌는지 확인

## 6. 인터넷 단어장 (v0.1.0 신규)

사전 준비: 단어장은 이미 GitHub에 있다 — `https://github.com/guesswhoisbackk/wordbook`.
기기에 입력할 URL: `https://cdn.jsdelivr.net/gh/guesswhoisbackk/wordbook@main`
(로컬 클론 `C:\antigravity\wordbook`, 갱신은 `scripts\push_wordbook.ps1`. NAS 등 다른 서버를 쓸 때는 평문 http://도 지원한다.)

- 설정 페이지(`http://<기기IP>/`)에 "단어장 (인터넷)" 섹션이 있는지
- 준비한 URL을 입력·저장한 뒤 재부팅하면 하단 상태가 `WB 8`처럼 단어 수로 바뀌는지
- 오늘 차례 단어가 내장 샘플이 아닌 단어장의 단어로 바뀌는지 (단어 수에 따라 며칠씩 걸릴 수 있음)
- 그림 있는 단어(`apple`) 차례에 그림이 카드에 뜨는지 — 그림 확인을 위해서는 `words.jsonl`에서 `apple`을 오늘 순번 위치로 옮기면 바로 시험 가능
- 인터넷 연결을 끊고 재부팅해도 캐시된 단어장(`WB CACHED`)으로 같은 카드가 뜨는지
- URL을 지우고 저장하면 내장 샘플 단어로 돌아가는지
- 시리얼 로그에 `[wb]` 줄이 오류 없이 나오는지 (manifest synced, card #N, art)

## 7. 안정성

- 30분 이상 켜 두고 재부팅·멈춤·화면 깨짐이 없는지
- 공유기 재시작 후 다시 연결되는지
- 설정(SSID, 밝기, 단어장 URL)이 재부팅 후 유지되는지

## 문제가 생기면 받을 정보

- 보드 앞·뒷면 사진과 모델 표기
- 사용한 BIN 파일명
- 화면 사진 또는 짧은 영상
- USB 시리얼 모니터 115200 baud 로그
- 화면 하단에 표시된 현재 IP 또는 AP 이름

이 정보가 있으면 디스플레이 핀, 터치 보정, 패널 종류, NTP 문제를 구분해서 고칠 수 있습니다.
## v0.2.0 추가 검증 (아직 실물 미검증)

- 기존 설정·캐시가 있는 ILI9341 보드에 앱 영역만 업데이트한 뒤 Wi-Fi 설정이 유지되는지 확인.
- 앞면에서 AGAIN/GOT IT이 비활성화되고, 정답을 확인한 뒤에만 평가할 수 있는지 확인.
- 긴 단어가 가로 스크롤되고 긴 뜻/예문은 답 영역에서 세로 스크롤되는지 확인. 스크롤이 카드 뒤집기로 잘못 인식되지 않아야 함.
- AGAIN → REVIEW → 완료 안내 → 10분 후 REVIEW에서 같은 단어가 정답을 숨긴 상태로 나오는지 확인.
- GOT IT 직후 재평가 방지, 재부팅 후 예약 유지, 기한 지난 단어 우선 선택을 확인.
- HINT 그림 표시 후 GOT IT이 막히고 AGAIN으로 평가되는지 확인. 그림이 없는 카드에서는 HINT 비활성화.
- 서로 크기가 다른 PNG 카드 간 전환 시 옛 그림/크기가 남지 않는지 확인.
- 인터넷 없이 재부팅했을 때 캐시 텍스트가 나오고, 시간 미확정 상태에서는 평가를 저장하지 않는지 확인.
- 서버 중단 시 10분 내 연속 다운로드가 발생하지 않는지 로그 확인.
- 잘린 Content-Length 응답, 잘못된 JSON, 512바이트 초과 항목, FS 용량 부족에서 기존 manifest가 유지되는지 확인.
- 빈 줄과 마지막 개행이 없는 words.jsonl에서 단어 수가 정확한지 확인.
- 같은 날 manifest를 갱신하여 뜻 수정/단어 순서 변경/현재 단어 삭제를 시험. 현재 단어가 남으면 최신 내용으로 유지하고, 삭제되면 오늘 슬롯으로 전환해야 함. 오프라인으로 그림 없이 선택한 카드도 재연결 후 동기화에서 그림을 받아야 함.
- KST 자정에 새 카드로 바뀌고 이전 카드의 답이 노출되지 않는지 확인.
- 스피커 재생은 이번 버전에 없음. 제품과 연결 확인 후 별도 검증.
