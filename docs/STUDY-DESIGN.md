# 순차 학습과 기한 복습 — v0.4.0

사용자는 가장 공부하기 좋은 방식을 추천해서 목표 모드로 구현해 달라고 요청했다. 선택한 흐름은 **기한 복습 → 다음 미학습 단어 → 스스로 뜻 떠올리기 → 답·예문 확인 → 평가 → NEXT**다. 발음을 듣고 따라 말할 수 있고, 그림은 힌트로만 먼저 보여준다.

회상·피드백·간격 복습을 조합한 학습은 [어휘 학습 실험](https://pmc.ncbi.nlm.nih.gov/articles/PMC8638698/)을 참고한다. 이 연구가 이 기기의 하루 5개나 10분/1·3·7·14·30일 간격을 개인별 최적값으로 입증하는 것은 아니다. 지속하기 쉬운 시작값으로 하루 5개를 정하고 0~20개 설정을 제공한다.

## 정책과 저장

- 목록 순서에서 처음 미학습 단어를 선택하되, 기한이 가장 오래 지난 복습을 우선한다. 날짜를 카드 번호로 사용하지 않는다.
- 최초 평가만 오늘의 신규 수를 증가시킨다. AGAIN도 신규 도입에 포함되며, 같은 단어 재평가는 포함하지 않는다. KST 자정에 수가 초기화되고 쉬었던 날의 분량은 누적하지 않는다.
- 단어 철자의 64비트 키로 학습 이력을 보존한다. 순서 변경은 배운 단어를 새 단어로 만들지 않으며, 동기화에서 삭제된 카드는 교체한다.
- 1,000개 기록을 힙에 저장한다. LittleFS의 검증된 스냅샷을 임시 파일로 쓰고 원자적으로 교체한다. 실패하면 메모리의 평가·오늘 수를 복원한다.
- 이전 NVS 128개 배열은 복습 시각·단계를 유지해 이전한다. 신규 슬롯은 비어 있는 단계에서 시작한다. 구형 NVS는 복구용으로 남겨 두지만 v0.4.0 실행 후의 기록은 파일이 기준이다.
- 파일시스템 마운트에 실패해도 기존 비어 있지 않은 파티션은 포맷하지 않는다. 완전히 지워진 첫 설치 파티션만 초기화한다. 손상된 이력은 저장을 중지하고 화면에 오류를 표시한다.
- 평가 저장 공간이 부족하면 다운로드한 음성·그림 캐시를 지워 공간을 확보한다. manifest·이력은 지우지 않는다. 신규 manifest에는 최대 이력 두 스냅샷과 메타데이터용 약 40KiB를 제외한 용량 상한을 적용한다.

## 검증

`scripts/test_host.cmd`는 우선순위·시간 경계·하루 수·복원·쓰기/이름 변경 실패·1,000개 이력·희소한 구형 이력 이전·캐시가 가득 찬 상황을 검사한다. 실패한 테스트는 Windows의 음수 종료 코드도 잡아낸다.

두 패널 빌드와 코드 리뷰를 실행한다. 실물 화면·터치·마운트 실패/전원 차단·오디오와 저장 병행은 `HARDWARE_TEST.md`의 v0.4.0 항목에서 별도로 확인해야 한다.
